# Design notes

Long-form argument for the *current* design. Each file expands a section of
[`../design.md`](../design.md) and is linked from the section it expands.

This is not a place to put proposals. A document describing something that is not
built yet, or that depends on one instance's data, is temporary: it belongs in
`.designs/` (gitignored) until the work lands, at which point its rule moves into
`design.md` before the file is deleted. What lives here is present-tense
description of what WarTable is, written for someone who has no access to the
author's database.
